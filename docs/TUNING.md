# TapeLofi エンジンのチューニング記録（V2）

仕様書 P002 v0.7 で「確定」している部分（パラメータ、6段EQテーブル、処理順序、発振器周波数、
バイカッド型、リサンプラ定数 0.995／0.95、4 ms ライン）には手を入れていません。
以下は、仕様書が「推定／未確定」としている部分を、実測に基づいて調整した記録です。

## 測定条件

48 kHz、1 kHz 正弦波、ピーク 0.5（−6 dBFS）。Probe 側のテスト信号レベルは仕様書に記載が無いため、
この条件は私が決めた仮定です。ズレた場合は `TapeEngine.cpp` の `kDirtDrive` / `kAgeDrive` を調整してください。

## サチュレーション

| 項目 | V1 | V2 | 目標（Probe） |
|---|---|---|---|
| Dirt 0／Age 0 | −0.63 dB、THD+N −29 dB | +0.07 dB、−40 dB | ほぼ素通し |
| 既定（Dirt 20／Age 10） | −1.4 dB | −0.11 dB | 軽い味付け |
| Dirt 100 | −4.9 dB | −1.2 dB | −1.4 dB |
| Age 100（Dirt 20） | −10.6 dB | −3.4 dB（＋ダークニング） | −4.9 dB |
| Dirt 100＋Age 100 | −12.4 dB | −4.9 dB | － |

- `x(27+x²)/(27+9x²)` は |x|<3 でのみ tanh 近似として有効（x=3 で ±1、傾き 0）。V1 はクランプしておらず、
  大入力で x/9 に漸近して「飽和せず減衰する」挙動になっていた。V2 は ±3 でクランプ
- 各段は `C·sat(g·x/C)/g`（C=2）。小信号ゲインは常に 1、天井は C/g
- Age 100 の −4.9 dB のうち、サチュレーションは約 −3 dB。残りは高域ロールオフ由来と解釈
  （Probe のテスト信号は低域が少ない広帯域とされており、正弦波より高域の影響が大きいため）
- 元製品の定数 0.8212／0.8932／0.8146 は、式の組み立てが未確定のため使っていません

## 未解決のまま残しているもの

- 元の飽和式そのもの（音の歪み方は元製品と別物）
- 変調の深さ換算（Wow ±1.1 ms、Flutter ±0.22 ms は仮定）。Age による増加は最大 +30 %
- 50 Hz 発振器の用途、ノイズ整形フィルタ（400 Hz 一次 HP で代用）
- リサンプラの窓関数（Blackman で代用）。48 kHz で 22 kHz が −3.7 dB、20 kHz は −0.2 dB
- High Cut の正規化値は元製品と逆向き（元は 0＝35 kHz、本実装は 0＝1 kHz）。元プリセット（D-09）を
  取り込む段階で、必要なら変換が要る
